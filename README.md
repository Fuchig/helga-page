# Helga Pataki

A minimal, responsive redesign of [Fuchig/helga-page](https://github.com/Fuchig/helga-page).

Plain HTML, CSS, and JavaScript. No build tools or dependencies.

## Preview

Run `python3 -m http.server 8080` in this directory, then open http://localhost:8080.

https://fuchig.github.io/helga-page/

## Features

- Responsive character profile and original character artwork
- Tough / soft personality switch
- Expandable relationship stories, usable without JavaScript
- Light and dark themes, following system preferences until manually changed
- Saved theme preference, keyboard focus styles, and reduced-motion support

Artwork is referenced from the original repository. Google Fonts and artwork need an internet connection. When applying this redesign to the original repository, the image URLs can be replaced with its existing local `images/` paths.

Original page by Tasha Fuchig, created during a Tap Tap Kaboom class. Characters belong to their respective owners.
